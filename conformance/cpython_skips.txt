# Tests of CPython's asyncio suite that do not apply to ringloop.
# pattern: reason        (fnmatch against module.Class.test_name)
# [3.12,3.13] pattern: reason      (those CPython versions only)
# [3.14+] pattern: reason          (3.14 and newer)

# -- asyncio's handle lock ----------------------------------------------------
# asyncio's private _ThreadSafeHandle holds a lock while its callback runs, so
# cancel() and cancelled() called from another thread wait for the callback.
# A ringloop handle never blocks the caller: cancel() from another thread
# takes effect if the callback has not started.
[3.14+] test_events.*.test_call_soon_threadsafe_handle_block_cancellation: cancel() does not wait for a running callback
[3.14+] test_events.*.test_call_soon_threadsafe_handle_block_check_cancelled: cancelled() does not wait for a running callback
[3.14+] test_events.*.test_call_soon_threadsafe_handle_cancel_same_thread: asserts the handle is asyncio's private _ThreadSafeHandle
[3.14+] test_events.*.test_call_soon_threadsafe_handle_cancel_other_thread: asserts the handle is asyncio's private _ThreadSafeHandle

# -- one loop, not three --------------------------------------------------------
# The suite runs the same tests on asyncio's loop with three selectors. The
# selector argument means nothing here: the EPollEventLoopTests copy runs.
test_*.PollEventLoopTests.*: same tests as EPollEventLoopTests
test_*.SelectEventLoopTests.*: same tests as EPollEventLoopTests
